# Task 5 — Research Report: Social Engineering Attacks

**Track:** OIBSIP Security Analyst Internship
**Author:** Morakinyo

## About This Project

This is a research report covering the main categories of social engineering attacks:
- Phishing (spear phishing, whaling, vishing, smishing)
- Pretexting
- Baiting
- Quid Pro Quo (bonus)

For each technique, the report explains how it works, walks through a real-world case study, and lists specific prevention recommendations. It closes with a comparison table and a 5-point employee security awareness training checklist for organizations.
