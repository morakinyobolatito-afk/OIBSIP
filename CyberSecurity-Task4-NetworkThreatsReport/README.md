# Task 4 — Research Report: Common Network Security Threats

**Track:** OIBSIP Security Analyst Internship
**Author:** Morakinyo

## About This Project

This is a research report covering four of the most common network security threats:
- Denial-of-Service / Distributed Denial-of-Service (DoS/DDoS)
- Man-in-the-Middle (MITM) attacks
- IP Spoofing
- DNS Poisoning / Spoofing (bonus threat)

For each threat, the report explains how the attack works, walks through a real-world example, describes its impact, and lists specific mitigation strategies. It closes with a comparison table across all four threats and a conclusion with key takeaways for a network administrator.
