# Task 6 — Research Report: The Importance of Patch Management

**Track:** OIBSIP Security Analyst Internship
**Author:** Morakinyo

## About This Project

This is a research report explaining what patch management is, why unpatched systems represent one of the largest attack surfaces in cybersecurity, and how organizations should implement an effective patching strategy. It covers:
- Why patches matter and how vulnerabilities move through the CVE/CVSS lifecycle
- Two real-world breaches caused by unpatched systems: WannaCry/EternalBlue (2017) and Equifax (2017)
- Consequences of not patching
- The patch management lifecycle (Discovery → Assessment → Testing → Deployment → Verification)
- A 7-step best-practices checklist
- Common challenges organizations face and how to overcome each
